ARREGLO DE FOTOS PARA LA PÁGINA DE STEPHANY 💗

Sube index.html, estilo.css y script.js en la raíz del repositorio. También sube la carpeta fotos completa; dentro deben estar recuerdo1.jpg, recuerdo2.jpg y recuerdo3.jpg.

La estructura en GitHub debe verse así:
index.html
estilo.css
script.js
fotos/recuerdo1.jpg
fotos/recuerdo2.jpg
fotos/recuerdo3.jpg

No pongas las fotos dentro de otra carpeta adicional. Si GitHub no permite subir una carpeta vacía, no importa: la carpeta fotos tiene que contener las tres imágenes.

Después de subir, espera 1-3 minutos y recarga la página publicada con Ctrl+F5.
